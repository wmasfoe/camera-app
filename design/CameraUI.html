Design Tokens

Color

--bg #000 — Pure black, OLED-safe
--surface #1a1a1a — Preview bg
--surface-2 #252525 — Button bg
--text #fff — Primary text
--text-muted #8e8e93 — Secondary
--accent-dim #636366 — Borders

Typography

System font stack. SF Pro on iOS, Roboto on Android.
Sizes: 12px labels, 14px buttons, 16px headings.
Weight: 500 medium, 600 semibold.

Spacing

Shutter: 72px diameter, 3px ring.
Filter pills: 6px 14px padding, 14px radius.
Action buttons: 10px 24-28px padding, 20px radius.
Bottom safe area: 40px.

Principles

  • Pure black bg — no gradients on camera surface
  • System fonts only — no custom type
  • No emoji anywhere
  • Minimal chrome — preview fills screen
  • Pill-shaped filters, not chips or cards
  • Shutter uses border+fill, not icon
  • All controls have clear hit states
